# TV apps

Pagini pentru launcherul TV, publicate pe GitHub Pages și reîmprospătate automat în fiecare luni.

- `site/fotbal/`: rezultate fotbal (ESPN, din browserul TV, fără server)
- `filme-seriale/`: topuri IMDb (datele oficiale IMDb, uz necomercial) + jurnalul Letterboxd bobec; rulează pe GitHub, nu pe laptop
- `.github/workflows/pagini.yml`: programul de actualizare (luni 04:17 UTC, sau manual din tabul Actions)
